Build a simple Node.js application called "Libraryminds Personal Video Generator" for personal use only (no authentication, no multi-user).
TECH STACK:
•	Backend: Node.js (Express)
•	Frontend: HTML + CSS + Vanilla JS
•	Libraries: axios, dotenv, fluent-ffmpeg, ffmpeg-static, uuid
ENV VARIABLES (.env):
AZURE_OPENAI_API_KEY=
AZURE_OPENAI_ENDPOINT=
AZURE_SPEECH_KEY=
AZURE_SPEECH_REGION=
FOLDER STRUCTURE:
/server.js
/services/openai.js
/services/avatar.js
/services/ffmpeg.js
/utils/srtGenerator.js
/public/index.html
/assets/logo.png
/assets/music.mp3
/assets/bg_vertical.mp4
/assets/bg_horizontal.mp4
/outputs/
________________________________________
FEATURES:
1.	SIMPLE UI:
•	Input field: Topic
•	Dropdown: Platform
Options:
o	YouTube Shorts (9:16, 20–30 sec)
o	Instagram Reels (9:16, 20–30 sec)
o	Facebook Reels (9:16, 20–30 sec)
o	YouTube Video (16:9, 60–90 sec)
o	Landscape Video (16:9, 30–60 sec)
•	Button: "Generate Video"
•	Progress display:
Script → Avatar → Editing → Done
•	Show final video + download button
________________________________________
2.	SCRIPT GENERATION (AUTO APPROVED)
Use Azure OpenAI:
Prompt:
"Create a highly engaging video script for [PLATFORM] on topic: [TOPIC].
Rules:
•	Strong hook in first 2 seconds
•	Short sentences
•	Natural pauses
•	End with: Follow Libraryminds
•	Duration:
Shorts/Reels: 20–30 sec
YouTube: 60–90 sec
Return clean script only."
________________________________________
3.	VOICE + VIDEO (SIMPLIFIED AVATAR FLOW)
IMPORTANT:
Instead of complex Azure Avatar API (which is unstable),
use this approach:
•	Generate voice using Azure Speech TTS
•	Save as outputs/voice.mp3
•	Use a pre-downloaded avatar video (assets/avatar.mp4)
•	Replace audio with generated voice
________________________________________
4.	CAPTIONS
•	Convert script → SRT
•	Each sentence = ~2 seconds
•	Save as outputs/subtitles.srt
________________________________________
5.	VIDEO PROCESSING (FFMPEG)
Inputs:
•	Avatar video
•	Background video
•	Logo
•	Music
•	Subtitles
•	Voice audio
LOGIC:
If platform is vertical:
Resolution: 1080x1920
Use bg_vertical.mp4
If platform is horizontal:
Resolution: 1920x1080
Use bg_horizontal.mp4
FFmpeg steps:
•	Loop background video
•	Overlay avatar (center)
•	Replace avatar audio with voice.mp3
•	Add subtitles (burn-in)
•	Add logo bottom-right
•	Add background music (low volume 0.1)
Output:
outputs/final.mp4
________________________________________
6.	ROUTE:
POST /generate
Flow:
1.	Generate script
2.	Generate voice (Azure TTS)
3.	Generate subtitles
4.	Run FFmpeg
5.	Return video path
________________________________________
7.	SIMPLICITY:
•	No database
•	No authentication
•	Single user only
•	Overwrite outputs each run
________________________________________
FINAL GOAL:
User enters topic → clicks generate → gets fully edited video with:
•	AI script
•	AI voice
•	Avatar video
•	Background
•	Logo
•	Captions
•	Music
All automatic, no manual editing.
