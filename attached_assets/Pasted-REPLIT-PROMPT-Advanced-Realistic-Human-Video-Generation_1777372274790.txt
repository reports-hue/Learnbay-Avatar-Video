REPLIT PROMPT — Advanced Realistic Human Video Generation
Make the video generation system as realistic and indistinguishable from a real human presenter as possible. Implement all of the following upgrades:

---

## 1. AZURE AVATAR — MAXIMUM REALISM SETTINGS

In avatarService.ts, update the Azure Avatar batch synthesis request body with these realism settings:

- Set `talkingAvatarCharacter` to "lisa" (most photorealistic Azure avatar)
- Set `talkingAvatarStyle` to "graceful-sitting" or "casual-sitting" — NOT standing. Seated avatars look far more natural and professional.
- Add `"videoFormat": "mp4"` and `"videoCodec": "h264"` to the output config
- Add `"backgroundColor": "#00FF00FF"` (green screen) so the avatar is isolated cleanly, then chroma-key composite her onto the gradient background in FFmpeg — this removes the ugly hard-cut rectangular avatar box
- In the SSML, add natural breathing pauses using `<break time="300ms"/>` between sentences, and `<break time="150ms"/>` after commas
- Add `<prosody rate="0.95" pitch="-2%">` wrapper inside the SSML — slightly slower rate and marginally lower pitch sounds far more natural than default TTS
- Add `<mstts:silence type="Sentenceboundary" value="200ms"/>` for natural sentence spacing

## 2. CHROMA KEY GREEN SCREEN COMPOSITING IN FFMPEG

In ffmpegService.ts, replace the simple avatar overlay with proper chroma key removal:

- After receiving the avatar MP4 (green screen background), use FFmpeg's `chromakey` filter: `[avatar]chromakey=0x00ff00:0.3:0.05[ckout]`
- Composite the keyed avatar onto the gradient background: `[bg][ckout]overlay=...`
- This makes the avatar appear naturally placed IN the scene, not pasted on top
- Scale the avatar to 85% of frame height, position centered horizontally, bottom-aligned with 40px padding from bottom

## 3. NATURAL HUMAN SCRIPT WRITING

In openai.ts, update ALL script style prompts with these rules:

- **Forbid** bullet points, numbered lists, or any list format in the script
- Require the script to be written as natural spoken monologue — the way a real person talks out loud, NOT how someone writes
- Add instructions: "Use contractions (I'm, we've, you'll, it's). Include one natural filler transition like 'So here's the thing' or 'And look' or 'Now the interesting part is'. Vary sentence length — mix short punchy sentences with longer explanatory ones. Never start two consecutive sentences with the same word."
- For Viral Hook style: "Open with a bold contrarian statement or surprising stat. First 3 seconds must create pattern interrupt."
- For Story style: "Begin in the middle of action. Use 'I was...' or 'Last week...' — make it feel like a real personal experience."
- Add a `naturalismScore` instruction: after generating the script, review it and replace any phrase that sounds 'AI-generated' or formal with a more casual human equivalent.

## 4. VOICE — HUMAN-SOUNDING TTS CONFIGURATION

In the Azure Speech SDK call (speech.ts), update to use these voices which sound most human:

- Primary voice: `en-US-AvaMultilingualNeural` (most natural Azure voice as of 2024)
- Alternative: `en-US-AndrewMultilingualNeural` (for male)
- Add these SSML enhancements per sentence:
  - Random micro-variation in rate: alternate between `rate="0.93"` and `rate="0.97"` per sentence (humans don't speak at perfectly constant speed)
  - Add `<mstts:express-as style="chat">` wrapper for conversational tone
  - For emphasis words (words in ALL CAPS in the script), wrap with `<emphasis level="moderate">`

## 5. PROFESSIONAL VIDEO POST-PROCESSING

In ffmpegService.ts, add these FFmpeg filters to the filter chain for cinematic realism:

**Color grade (makes it look camera-shot, not screen-recorded):**
eq=brightness=0.02:saturation=1.1:contrast=1.05

**Subtle film grain (makes it organic, not digital-sterile):**
noise=alls=4:allf=t+u

**Slight vignette (broadcast standard):**
vignette=PI/6

**Sharpening (avatar detail enhancement):**
unsharp=3:3:0.6:3:3:0.0

**Frame rate normalization to exactly 30fps** (inconsistent fps is a dead giveaway):
fps=30

**Micro zoom-in over duration (Ken Burns effect — simulates camera operator):**
Use `zoompan` filter: very slowly zoom from 1.00 to 1.03 over the full video duration. This subtle camera movement makes static avatar video feel alive and filmed.

## 6. ANIMATED WORD-HIGHLIGHT CAPTIONS — HEYGEN STYLE

In the caption/subtitle system, upgrade to:

- Font: Use `Arial Bold` or `Helvetica Neue Bold` (fallback to DejaVu-Bold)
- Caption style: Show MAX 3 words at a time centered on screen (not full sentences)
- Position: Bottom 30% of frame (above brand bar)

## 7. AUDIO ENHANCEMENT

After generating the TTS audio (speech.ts), apply these FFmpeg audio filters before merging with video:
loudnorm=I=-16:TP=-1.5:LRA=11
(This normalizes loudness to broadcast standard — -16 LUFS, same as YouTube/Instagram. Raw TTS is often too quiet or uneven.)

Also add subtle room reverb to remove the "recorded in a vacuum" TTS sound:
aecho=0.8:0.9:40:0.3

Background music: Set to 6% volume (currently 10% is too loud — voice should dominate). Fade music in over first 1 second and fade out over last 1.5 seconds using `afade`.

- Add a `topTextOverlay` parameter: if script has a hook/title, burn it as large text in the top safe zone (first 3 seconds only, then fade out).
