## SINGLE NEW TASK TO IMPLEMENT

Switch the Azure Avatar API to request a transparent WebM background instead of green screen. This eliminates the FFmpeg chroma key step entirely and gives perfect avatar edges with zero green fringe.

Steps:
1. In avatarService.ts: set videoFormat "webm", videoCodec "vp9", backgroundColor "transparent" in the avatar batch synthesis request body
2. The API returns a .webm file with a real alpha channel — no green screen, no chroma key needed
3. In ffmpegService.ts: remove the colorkey/chromakey filter. Overlay the WebM directly onto the background using FFmpeg overlay filter — transparency is already baked in
4. Update the avatar file download to save as .webm not .mp4
5. Test that avatar edges are clean with no green fringe or halo before marking done

NEVER use videoFormat "mp4" with backgroundColor "transparent" — Azure requires webm+vp9 for transparent output
NEVER remove the chroma filter without first confirming the WebM transparent path works end-to-end

## HARD RULES — CAPTION TIMING — MOST CRITICAL

- NEVER calculate caption timing from character count, word count, or WPM estimates
- NEVER use fixed duration per subtitle line
- NEVER generate the ASS file before TTS synthesis completes and word timestamps are collected
- NEVER silently fall back to estimated timing — if Azure SDK returns zero word boundary events, throw a clear error
- The function estimateWordTimings() must not exist anywhere in the codebase — it is permanently deleted
- USE Azure Speech SDK wordBoundary events: audioOffset in ticks divided by 10,000,000 = seconds; duration in ticks divided by 10,000,000 = seconds; text = the word
- Group words into 3-5 word chunks. Chunk startTime = first word startSeconds. EndTime = last word startSeconds + durationSeconds
- Add 50ms gap between consecutive chunks. Safety floor: end must be at least startSec + 40ms
- Log first 5 word timestamps to server console on every render for verification

## HARD RULES — FFMPEG & VIDEO QUALITY

- NEVER use FFmpeg preset medium or slower — renders become 3-5x longer and appear frozen to the user
- NEVER draw a horizontal accent bar or stripe across the bottom of the video frame
- NEVER apply aecho reverb to ElevenLabs audio — it is already studio-mastered
- NEVER use caption BorderStyle 3 (opaque box) — only BorderStyle 1 (outline + shadow)
- Output encoding: -preset fast -crf 18 -profile:v high -level 4.1 -g 60 -keyint_min 60
- Audio output: -c:a aac -b:a 192k -ar 48000
- If still using green screen before transparent WebM is confirmed: chroma key similarity=0.30, blend=0.10, plus despill filter
