# Libraryminds Personal Video Generator

A no-auth, avatar video generation tool powered by Azure AI that creates personalized video content.

## Run & Operate

- **Run API server locally**: `pnpm --filter @workspace/api-server run dev`
- **Full typecheck**: `pnpm run typecheck`
- **Environment Variables**:
    - `AZURE_OPENAI_API_KEY`
    - `AZURE_OPENAI_ENDPOINT`
    - `AZURE_OPENAI_DEPLOYMENT` (defaults to `gpt-4o-mini`)
    - `AZURE_SPEECH_KEY`
    - `AZURE_SPEECH_REGION`
    - `LOGIN_EMAIL`
    - `LOGIN_PASSWORD`
    - `PEXELS_API_KEY` (for b-roll video search)
    - `FFMPEG_PATH` (optional, overrides default ffmpeg binary selection)

## Architecture decisions

- **No-Auth Login**: Uses single `LOGIN_EMAIL` and `LOGIN_PASSWORD` env vars for authentication, HMAC-SHA256 signed tokens for sessions. No database for users.
- **Script Review First**: Users always review and can edit AI-generated scripts before video rendering begins, saving costly avatar synthesis calls.
- **ElevenLabs Audio Swap**: ElevenLabs voices are synthesized separately and then swapped in during FFmpeg post-processing for avatar videos generated by Azure TTS, maintaining lip-sync with Azure's avatar.
- **Chroma Key Compositing for Realism**: Due to Azure Avatar API limitations with transparent WebM, green-screen MP4s are used with FFmpeg chroma keying for realistic avatar compositing.
- **Dynamic FFmpeg Binary Selection**: Auto-detects and prioritizes FFmpeg builds with `drawtext` support (like system-installed versions) over `ffmpeg-static` to ensure full feature compatibility.

## Product

- **User Authentication**: Simple single-user login with email/password from environment variables.
- **AI Script Generation**: Generates video scripts using Azure OpenAI (gpt-4o-mini) in various styles.
- **Avatar Video Synthesis**: Creates avatar videos using Azure AI Avatar Batch Synthesis API.
- **Customizable Brand Identity**: Users can define company identity, visual identity (logo, colors), and default video settings.
- **Advanced Video Features**: Includes realism mode (green-screen, color grade, film grain, Ken Burns), word-by-word captions, AI background images, ElevenLabs voice integration, and various visual effects (light leaks, beat-synced pulses, stat pop-ins).
- **Video Management**: Dashboard for quick creation, video library with search, preview, download, and delete functionalities.
- **Real-time Progress**: SSE (Server-Sent Events) for live job progress updates during video generation.

## Gotchas

- **FFmpeg `drawtext` filter**: `ffmpeg-static@5.3.0` does not include `drawtext`. Ensure a compatible FFmpeg binary is available in the PATH or specified via `FFMPEG_PATH`.
- **Azure Avatar API transparency**: Azure's batch synthesis API ignores `backgroundColor:"transparent"`. Always use green-screen with chroma keying for custom backgrounds.
- **FFmpeg comma escaping**: Commas within `enable='...'` filter expressions must be escaped as `\\,` in JavaScript string literals. Commas within `{...}` override blocks in ASS (e.g., `\pos(x,y)`) are plain.
- **API Key Logging**: Pexels API key is never logged. Only short error messages, HTTP status, and truncated queries are logged.
- **Video Deletion**: Deleted videos are tombstoned in local storage. They will not reappear on library mount unless explicitly recovered.
